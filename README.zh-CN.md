# CavernHelper

适用于 Shared 运行时的 CavernHelper 移植。工作区位置：`Mods/CavernHelper/`。

项目：

- `Celeste.Mods.CavernHelper.csproj`

依赖仓库：**Shared**。先按 [Tools README][tools-readme-zh-cn] 准备 Shared 资源，再构建主项目：

```powershell
dotnet build ./Mods/CavernHelper/Celeste.Mods.CavernHelper.csproj -c Release
```
